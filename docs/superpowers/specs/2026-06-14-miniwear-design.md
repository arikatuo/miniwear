# 宝宝今天穿什么 V1.0 技术设计

## 1. 目标与范围

按照《宝宝今天穿什么 V1.0 最终版 PRD》实现一个原生微信小程序。V1.0 提供今日三场景穿搭建议、首次设置、城市与天气、手动温度模式、宝宝设置、用品参考、分享卡、本地缓存和完整异常兜底。

不实现账号、云数据库、云同步、商城、广告、AI、长期偏好学习和医疗诊断。项目暂不使用 Git。

## 2. 技术方案取舍

### 采用：原生微信小程序 JavaScript

- 使用 WXML、WXSS、JavaScript 和微信小程序原生组件。
- 目录、路由和生命周期直接对应 PRD，降低首版复杂度。
- 推荐规则和用品数据使用独立配置模块，页面不硬编码业务规则。
- 核心业务函数保持纯函数，允许在 Node.js 下执行自动测试。

### 未采用：TypeScript 原生小程序

类型安全更强，但需要额外构建配置。当前项目为空且 V1.0 数据结构较小，收益不足以抵消交付复杂度。

### 未采用：Taro/uni-app

跨端不是 V1.0 目标，引入框架会增加依赖、构建链和排查成本。

## 4. 数据与状态

持久状态写入 `bbc_` 前缀缓存，入口统一由 `storage.service.js` 管理。服务负责：

- `storageVersion` 初始化和迁移；
- 单字段校验与默认值兜底；
- 最近城市最多保留 3 个；
- 清空全部业务缓存后重新写入当前版本；
- 天气缓存有效期 30 分钟。

页面临时状态不持久化，包括“想薄一点”“想厚一点”和分享弹窗状态。刷新天气、切换城市、修改室温和重新进入今日页时重置临时调整。

## 5. 推荐引擎

推荐引擎输入：

- 场景：在家、出门、睡觉；
- 场景温度：室温或室外温度；
- 月龄组；
- 体质；
- 是否容易出汗；
- 天气标签；
- 当前临时调整量。

计算顺序：

1. 根据场景和温度命中基准档位；
2. 应用体质修正；
3. 应用出汗修正；
4. 仅对出门场景应用天气修正；
5. 应用当前卡片临时修正；
6. 截断到最薄和最厚边界；
7. 生成推荐结果、原因、热了怎么办、冷了怎么办和月龄提示。

所有规则来自 `config/recommend.rules.js`。服务返回可直接渲染的 ViewModel，不让页面复制规则逻辑。

## 6. 天气与定位

定位必须由用户点击“一键定位”后触发。拒绝或失败时保留手动选城入口。

天气服务支持三种来源：

- 腾讯位置服务实时天气；
- 30 分钟本地缓存；
- 用户填写的手动天气。

天气 API Key 通过项目配置占位，不写入业务代码。未配置 Key、超时、请求失败时均进入 PRD 规定的缓存或手动模式。请求超时目标为 2 秒。

## 7. 页面与交互

- 首次设置：城市、室温、宝宝情况三步，均可跳过。
- 今日页：首屏先展示三场景摘要，详细卡片置于下方。
- 城市页：定位、城市关键词过滤、最近 3 个城市。
- 手动天气：室外温度、室内温度和多选天气标签。
- 用品页：穿衣/睡觉分组与子分类过滤，图片失败显示统一占位。
- 设置页：宝宝资料、环境、隐私和二次确认清除数据。
- 分享卡：Canvas 生成单模板图片，包含三场景结论、天气、判断标准和免责声明。
- 隐私页：展示 PRD 全部隐私和健康风险说明。

## 8. 视觉设计

采用温柔、干净、低饱和的浅色母婴风格：

- 主色 `#4A90D9`；
- 背景 `#F7FBFF` 与暖奶白；
- 卡片圆角 16px，轻阴影，充足留白；
- 结论文字明显大于天气和原因；
- 浅黄用于室温提示，浅绿用于成功反馈，柔和橙用于异常提示；
- 用品插画使用统一的本地矢量风格占位资源，不混用商品图。

V1.0 不实现深色模式。

## 9. 错误与边界

- 缓存字段损坏时使用单字段默认值，页面不得崩溃。
- 天气失败有缓存时显示缓存及更新时间；无缓存时跳转手动模式。
- 无城市时显示定位和手动选城入口。
- 推荐调整触达边界时保持原结果并给出明确提示。
- 分享卡失败、图片失败、城市搜索无结果均提供可恢复状态。
- 所有健康文案避免绝对表达，首页和分享卡展示免责声明。

## 10. 测试与验收

Node.js 自动测试覆盖：

- 温度区间边界；
- 月龄计算和默认月龄；
- 体质、出汗、天气修正；
- 最薄/最厚边界；
- 缓存迁移、校验和最近城市；
- 天气缓存有效期；
- 三场景推荐结构完整性。

静态验收覆盖全部路由、组件、隐私文案、免责声明和配置引用。微信开发者工具可用后，还需进行 Canvas、定位授权、保存图片、高 DPR 和 iPhone/Android 真机验收。

## 11. 完成标准

PRD 中全部 V1.0 页面和必须功能已实现；核心逻辑测试通过；项目可被微信开发者工具直接导入；无 API Key 时可完整使用手动天气路径；已知无法在本机自动证明的真机项目被明确记录。
