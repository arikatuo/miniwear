# V1.0 验收说明

## 已自动验证

- 推荐规则温度边界、体质修正、出汗修正、天气修正和临时调整边界。
- 月龄计算、默认月龄和 3 岁以上兜底。
- 缓存初始化、字段损坏兜底、最近城市和 30 分钟天气缓存。
- 全部页面和组件四件套存在。
- JSON 与 JavaScript 语法有效。
- WXML 未使用已知不兼容表达式。
- 首页、隐私页和分享卡均包含健康免责声明。
- 用品配置保留 54 个条目，其中 44 个目录可见、9 个历史夹棉规格仅用于兼容、1 个小毛巾护理条目不进入睡眠目录；另有 1 张中性 `default.jpg` 作为加载失败占位图。
- 衣柜床品截图素材已裁剪/清理/重建为 400x400 JPG 运行素材；源图中被底部栏或顶部栏截断的商品已移除，截图导航栏、文字标签和温度文字不作为商品文案进入图片。
- 商品运行素材从 PNG 转为 JPG 后，`assets/goods` 从约 6.31MB 降至约 0.48MB，开发工具上传包估算约 0.58MB，低于真机调试 2MB 限制。
- 上传包忽略开发文档、测试、脚本、PRD PDF 和原始截图目录，避免非运行素材进入小程序包。
- 分享卡 Canvas 高度与高清导出尺寸一致，小程序码绘制区域不会越过画布边界。
- 手动天气支持输入负温度，首次设置跳过异常室温时回退到默认 24℃。
- 微信开发者工具 `2.02.2606122` 已使用 `touristappid` 打开并编译项目。
- 开发者工具日志确认全部 7 个页面和 5 个组件进入编译流程；本轮素材与功能修复触发 WXML/WXSS 编译，未出现项目 WXML、WXSS、JavaScript 或组件编译错误。
- 开发者工具 CLI 服务端口已开启，可继续用于自动化验收。

## 微信开发者工具验收

1. 清空缓存进入首次设置。
2. 分别验证定位允许、拒绝和手动选城。
3. 未配置天气 Key 时进入手动天气并生成三场景建议。
4. 配置 Key 后验证 30 分钟缓存、主动刷新和失败缓存提示。
5. 验证“想薄一点”“想厚一点”的最薄/最厚边界和重置时机。
6. 验证用品筛选、图片失败占位和设置页清除数据。
7. 验证更新管理器提示不会阻塞正常使用。
8. 使用真实 AppID 生成固定小程序码，配置 `config/share.config.js` 后确认分享卡可识别。

## 真机验收

- iPhone 与 Android 的 Canvas 中文换行、高清输出和保存相册。
- 用户拒绝保存相册权限后的错误恢复提示。
- 定位权限说明与实际弹窗一致。
- 375px 小屏、大屏手机和横屏下无横向溢出。
- 今日页首屏建议可见时间不超过 1.5 秒。
- 分享卡生成不超过 3 秒。
- 分享卡中的免责声明清晰可见。

当前机器已具备微信开发者工具 CLI。由于开发者工具账号未登录，日志中存在 `access_token missing` 的云端同步错误；该错误不影响本地编译，但预览、上传、真实 AppID 权限和真机验收仍需登录后完成。
