# 界面与交互全面优化（2026-10-03）

目标：功能与业务逻辑不变，把"答案优先、一眼看懂、单手好用、看着舒服、值得转发"落到界面上。

## 约束（均已满足）
- 原生小程序、无运行时依赖；`npm run check`（测试 + 项目校验）全绿。
- 图片/音频资源总量 < 200 KiB（本次 0 字节新增，仍为 198,656 B）：只用 CSS、排版、动效和已有 JPEG 缩略图提升质感。
- 业务逻辑、`bbc_` 缓存键、天气接口、分享链路不变；健康免责声明全部保留。

## 设计系统
- 新增 `styles/shared.wxss`：场景主题（在家/出门/睡觉）、按钮、底部弹层、动效。`app.wxss` 与 5 个组件通过 `@import` 共用（组件样式隔离，必须各自引入）。
- 新增 `-ink` 文字色（对比度提升），主色阴影/渐变统一；卡片层级由 3 层减为 2 层。
